# Landi Boom

Site institucional e portfólio demonstrativo da Landi Boom.

## Estrutura

- `index.html`: página inicial.
- `servicos.html`: serviços e pacotes, com valores sob consulta.
- `portfolio.html`: apresentação dos projetos.
- `sobre.html`: sobre a empresa.
- `contato.html`: WhatsApp, e-mail e Instagram.
- `portfolio/`: demonstrações fictícias de eletricista, encanador e azulejista.

## Publicação

Site estático em HTML, CSS e JavaScript. No GitHub Pages, usar a raiz da branch `main` como origem. O arquivo `.nojekyll` preserva a publicação estática.

## Demonstrações

As empresas e profissionais dos projetos são fictícios. As imagens geradas por IA não representam trabalhos reais. Os formulários demonstrativos não enviam dados. As fontes web Barlow e Inter são carregadas do Google Fonts.
